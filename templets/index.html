01 / THE BASICS

Same from both directions.

A palindrome is a word, number or sentence that reads the same forward and backward after ignoring spaces, punctuation and letter case.

  • ✓ MADAM → MADAM
  • ✓ LEVEL → LEVEL
  • ✓ 12321 → 12321
  • × HELLO → OLLEH

DSA CONCEPT SPOTLIGHT

Meet the Stack.

Stack follows LIFO: Last In, First Out. The last character pushed is the first one popped. That's how the checker obtains the reversed text.
